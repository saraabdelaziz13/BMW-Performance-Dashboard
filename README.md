# 🚗 BMW Performance Dashboard | Excel Data Analysis

## 📌 Project Overview
This project presents an interactive BMW Performance Dashboard developed using Microsoft Excel. It transforms automotive sales data into meaningful insights through data analysis and visualization.

## 🎯 Project Objectives
- Analyze BMW sales performance.
- Compare revenue and sales across different models.
- Explore regional sales performance.
- Identify trends across different years.
- Understand fuel type and transmission distributions.

## 📊 Dashboard Features
- **KPI Cards:** Total Revenue, Sales Volume, and Average Price.
- **Model Analysis:** Compare performance across BMW models.
- **Regional Analysis:** Explore sales across different regions.
- **Fuel Type Analysis:** Analyze fuel type distribution.
- **Transmission Analysis:** Compare automatic and manual vehicles.
- **Yearly Trends:** Explore performance over time.
- **Interactive Filters:** Explore the data using dashboard filters.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Data Cleaning & Preparation
- Data Analysis
- Excel Charts
- Dashboard Design
- Data Visualization

## 💡 Key Learning Outcomes
Through this project, I practiced data cleaning, analyzing datasets, building interactive visualizations, and presenting insights through an organized dashboard.
